# eisol-connect

Return page for the HubSpot OAuth connection of EISOL's apps.

- It holds no secret, stores nothing and calls nothing by itself.
- It checks that the return address inside `state` belongs to the app (its Forge web trigger host), then forwards the one-time code there with a form POST.
- Address: https://connect.eisol.jp/hubspot/ (the old https://taketo.github.io/eisol-connect/hubspot/ redirects there)

Product pages for EISOL Field Sync (guide, pricing, privacy policy, DPA, support) are in `hubspot-jira/`, served at https://connect.eisol.jp/hubspot-jira/. They are generated by `scripts/build_product_site.py` in the product repository; edit the sources there, not these files.
